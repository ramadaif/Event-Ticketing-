1. User Registration :
User Story:
As a new user, I want to create an account, so that I can book tickets and access platform features.
Acceptance Criteria:
•	User can enter name, email, and password 
•	System validates input data 
•	Account is created successfully 
•	User receives confirmation message 
Priority: High
2. User Login :
User Story:
As a registered user, I want to log into my account, so that I can access my bookings and personal data.
Acceptance Criteria:
•	User enters email and password 
•	System verifies credentials 
•	User is redirected to dashboard upon success 
•	Error message shown for invalid login 
Priority: High
3. Browse Events :
User Story:
As a user, I want to browse available events, so that I can choose what I want to attend.
Acceptance Criteria:
•	Events are displayed in a list 
•	Each event shows name, date, location, and price 
•	Events are updated dynamically 
Priority: High
4. Search for Events :
User Story:
As a user, I want to search for events, so that I can quickly find specific events.
Acceptance Criteria:
•	Search by event name or category 
•	Relevant results are displayed 
•	Message shown if no results found 
Priority: Medium
5. View Event Details :
User Story:
As a user, I want to view event details, so that I can decide whether to book tickets.
Acceptance Criteria:
•	Detailed event page is displayed 
•	Includes description, date, time, venue, and price 
•	Clear “Book Ticket” button is available 
Priority: High
6. Book Ticket :
User Story:
As a user, I want to book tickets for an event, so that I can attend it.
Acceptance Criteria:
•	User selects number of tickets 
•	System calculates total price 
•	Booking is confirmed after submission 
•	Confirmation message is displayed 
Priority: High



7. Payment Process :
User Story:
As a user, I want to choose a payment method, so that I can complete my booking.
Acceptance Criteria:
•	Multiple payment options available (e.g., cash or online) 
•	Payment status is updated 
•	Successful payment confirmation shown 
Priority: High
8. View Booking History :
User Story:
As a user, I want to view my booking history, so that I can track my past and upcoming events.
Acceptance Criteria:
•	List of previous bookings displayed 
•	Each booking shows event details and status 
•	User can access booking information anytime 
Priority: Medium
9. Cancel Booking :
User Story:
As a user, I want to cancel a booking, so that I can manage my reservations.
Acceptance Criteria:
•	User selects a booking to cancel 
•	System confirms cancellation action 
•	Booking status is updated 
Priority: Medium
10.	Manage User Profile :
User Story:
As a user, I want to update my profile information, so that my account details stay accurate. 
Acceptance Criteria:
• User can edit name, phone number, or password
• System validates updated information
• Changes are saved successfully
• Confirmation message is displayed
Priority: Medium

User Story:
As a user, I want to receive a booking confirmation, so that I can verify my reservation details. 
Acceptance Criteria:
• System sends confirmation after booking
• Confirmation includes event details and ticket information
• User can view confirmation in the account dashboard
Priority: High

12.	Event Categories :
User Story:
As a user, I want to browse events by category, so that I can easily find events that interest me. 
Acceptance Criteria:
• Events are grouped into categories
• User can select a category filter
• Filtered events are displayed correctly
Priority: Medium
