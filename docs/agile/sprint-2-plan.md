Deliver the core ticketing and payment workflow so that users can book tickets, complete payment, and receive a booking confirmation. Additionally, provide basic event search functionality to improve event discovery.

Duration:  
2 weeks  (Week 3 – Week 4)
Sprint Velocity:  
16 Story Points
Team Members:  
All 7 members — see assignments below
