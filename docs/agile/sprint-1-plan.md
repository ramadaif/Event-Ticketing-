Sprint 1 — Plan

Sprint Goal:
Establish the core user authentication and basic event browsing experience so that users can register, log in, and view available events on the platform.
Duration:  2 weeks  (Week 1 – Week 2)
Sprint Velocity:  18 Story Points
Team Members:  All 7 members — see assignments below
Selected User Stories
Story ID	User Story	Effort (SP)	Assignee	Priority

US-02	As a registered user, I want to log into my account so that I can access my bookings and personal data.	5	Abdelrahman & Yousef	High
US-03	As a user, I want to browse available events so that I can choose what I want to attend.	5	Yousef & Abdelrahman	High
