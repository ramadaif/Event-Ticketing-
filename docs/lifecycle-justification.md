1. Introduction
The Event Ticketing Platform is a system designed to allow users to browse events, book tickets, and manage their reservations. The system includes features such as event listing, ticket booking, payment options, and user account management.
Since this project involves user interaction and evolving requirements, choosing the right Software Development Life Cycle (SDLC) model is important to ensure efficiency and quality.
________________________________________
2. Chosen SDLC Model: Agile (Scrum)
The Agile (Scrum) model was selected because it focuses on iterative and incremental development. The project is divided into small parts called sprints, where each sprint delivers a working piece of the system.
________________________________________
3. Justification for Choosing Agile
3.1 Flexibility and Changing Requirements
In a system like an event ticketing platform, user needs may change over time (for example, adding new payment methods or improving the booking process).
Agile allows easy modification of requirements between sprints without affecting the entire system.
________________________________________
3.2 Continuous User Feedback
The platform depends heavily on user experience. Agile supports continuous feedback by:
•	Delivering working features in each sprint 
•	Allowing testing and improvements based on user opinions 
This helps in building a better final product.
________________________________________
3.3 Faster Delivery of Features
Instead of waiting until the end of the project, Agile enables:
•	Development of small features step by step 
•	Early delivery of core functionalities (ex  , registration → browsing events → booking) 
This ensures visible progress throughout the project.
________________________________________
3.4 Better Team Collaboration
Agile promotes:
•	Strong communication between team members 
•	Task division into smaller, manageable parts 
•	Regular follow-ups 
This improves team coordination and reduces misunderstandings.
________________________________________
3.5 Risk Reduction
Since development is done in iterations:
•	Problems are detected early 
•	Issues can be fixed before they grow 
This reduces overall project risk compared to models like Waterfall.
________________________________________
4. Alignment with Project Nature
The Event Ticketing Platform is well-suited for Agile because:
•	It includes multiple features that can be developed incrementally 
•	It relies on user experience and feedback 
•	It is scalable and can be improved over time 
•	New features can be added easily in future sprints 
________________________________________
5. Conclusion
Based on the project requirements, Agile (Scrum) is the most suitable model because it provides:
•	Flexibility in handling changes 
•	Faster delivery of features 
•	Continuous improvement through feedback 
•	Reduced development risks 
This makes it easier to build an effective and user-friendly
