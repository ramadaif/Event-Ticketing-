# Event Ticketing Platform

---

## Overview

The **Event Ticketing Platform** is a C++-based system that allows users to browse, create, and book events in an organized and efficient way.

The system simulates a real-world ticket booking environment where users can register, explore events, reserve tickets, and manage their bookings.

---

## Problem Statement

Many users face difficulties when trying to:

* Find available events in one place
* Book tickets easily and quickly
* Manage or cancel bookings efficiently
* Track event availability in real time

Event organizers also struggle with managing registrations and ticket allocations manually.

---

## Solution

The Event Ticketing Platform solves these problems by:

* Providing a centralized system for event management
* Allowing users to browse and search available events
* Enabling fast and structured ticket booking
* Supporting booking updates and cancellations
* Managing event capacity automatically

---

## Target Users

* **Users / Attendees:** People looking to attend events and book tickets
* **Event Organizers:** Individuals or admins managing events and ticket availability

---

## Key Features (MVP)

* User registration and login system
* Event creation and management
* Browse and view available events
* Ticket booking system
* Booking cancellation
* Basic user dashboard
